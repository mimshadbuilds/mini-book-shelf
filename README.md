# Book Shelf

Book Shelf is a modern book discovery and reading-list application built with Next.js. Users can explore books, view detailed information, add books to their read list or wishlist, sort listed books by filters, and manage their listed books through a simple and responsive interface.

## Live Project

🔗 **Live Demo:** [Live link](https://mini-book-shelf.vercel.app/))

---

## Project Overview

Book Shelf is designed to provide a clean and intuitive experience for discovering and managing books.

The application includes a book listing page, individual book details pages, read and wishlist functionality, sorting capability, loading states, responsive layouts, and reusable components.

Books are retrieved from an API and displayed using reusable React components. The application also uses the React Context API to manage the user's read books and wishlist across the application. Also, this app shows the user's book-reading data through modern Recharts!

---

## Features

- 📚 Browse a collection of books
- 🔍 View detailed information about individual books
- ⭐ Display book ratings
- 🏷️ Display book categories and tags
- 📖 Add books to the Read Books list
- ❤️ Add books to the Wishlist
- 📚 Sort book list by condition 
- 📋 View Read Books and Wishlist Books separately
- 🔗 Navigate from book cards to detailed book pages
- 📱 Responsive design for mobile, tablet, and desktop
- ⏳ Loading skeletons for book cards
- ⏳ Loading skeleton for book details pages
- ❌ Custom not-found pages
- 🎨 Clean and minimal UI
- 🧩 Reusable React components
- 🌐 Server-side data fetching with Next.js
- ⚡ Fast navigation using Next.js App Router
